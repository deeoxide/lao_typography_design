# Lao to English translation

> **Default font:** unless the user names a font, use **Noto Sans Lao** for all Lao text, designs and fonts, automatically and without asking. Use another font (for example Phetsarath OT or Noto Serif Lao) only when the user, an official template or a brand guide asks for it.

Translate the supplied Lao into natural English suited to the user's audience. This skill handles Lao-to-English work; do not start an English-to-Lao pass unless requested.

## Working method

- Inspect source legibility before interpreting it. Garbled encoding or uncertain OCR requires a verified reading or an explicit uncertainty note, not an invented sentence.
- Preserve the source's meaning, tone, headings, lists, table relationships, and substantive detail. Lao can omit subjects; infer a subject only when context supports it and flag consequential ambiguity.
- Keep names, brands, addresses, identifiers, units, and amounts accurate. Prefer supplied official English spellings; otherwise identify uncertain romanization rather than presenting it as official.
- Keep calendar and currency values unchanged unless conversion is requested. Verify digit transcription and do not silently recalculate figures.
- Translate idioms and institutional terms for meaning. Use a short explanatory note where a literal English equivalent would mislead. Maintain a consistent glossary for repeated terms.
- Preserve uncertainty from the source and distinguish translator notes from translated content. Do not silently correct questionable facts in the original.

For bilingual output, place source and translation in separate labeled blocks or aligned table cells. When retaining Lao in a formatted file, preserve its Unicode and use a font and rendering path that support its combining marks.

Return the translation first, followed by only the notes needed to explain ambiguity or terminology. Compare names, numbers, dates, and omissions against the Lao before delivery. State when a specialist or native review remains necessary for the intended use.
