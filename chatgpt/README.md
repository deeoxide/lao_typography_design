# Use this project in ChatGPT

ChatGPT does not read `SKILL.md` folders in a normal chat, so this folder packages the same rules for a **Custom GPT**, a **ChatGPT Project**, or a one-off chat. Menu names in ChatGPT change from time to time; the steps below describe what to look for.

## Files

| File | What it is |
|---|---|
| [`custom-gpt-instructions.md`](custom-gpt-instructions.md) | The instructions to paste. 5,600 characters, under the 8,000-character limit for GPT instructions. |
| [`lao-typography-knowledge.md`](lao-typography-knowledge.md) | One knowledge file made from all the reference notes (alphabet, vowels, typography, Unicode, recipes, fonts). Generated by `python3 bin/build_plugin.py`; do not edit by hand. |
| [`../lao_typography_design/scripts/lao_check.py`](../lao_typography_design/scripts/lao_check.py) | The checker the instructions tell the GPT to run. Upload it as a knowledge file. |
| [`../lao_typography_design/assets/fonts/`](../lao_typography_design/assets/fonts/) | Lao fonts. Upload at least `NotoSansLao-VariableFont_wdthwght.ttf`: Code Interpreter usually has no internet and no Lao font. |
| [`../lao_typography_design/references/images/`](../lao_typography_design/references/images/) | The consonant and vowel charts (French). Optional. |

## Custom GPT

1. In ChatGPT, create a GPT (Explore GPTs, then Create, then Configure).
2. **Name:** Lao Typography Assistant. **Description:** Lao language, Unicode and typography: translate, proofread, typeset, and build Lao documents with the right fonts.
3. **Instructions:** paste the whole of `custom-gpt-instructions.md`.
4. **Knowledge:** upload `lao-typography-knowledge.md`, `lao_check.py`, `NotoSansLao-VariableFont_wdthwght.ttf`, and any other fonts you want available.
5. **Capabilities:** turn on **Code Interpreter** (needed to build files and run the checker). Turn off image generation: image models draw Lao letters badly. Web search is optional.
6. **Conversation starters** (suggested):
   - Translate this English paragraph into Lao and tell me what is ambiguous.
   - Make a one-page Lao price list as a Word file and a PDF.
   - My Lao text shows boxes in PowerPoint. What is wrong?
   - Check this Lao document for typography problems.
7. Test with the starters, then open each generated file and look at it.

## ChatGPT Project

Create a project, paste `custom-gpt-instructions.md` into the project instructions, and add the same files as project files.

## One-off chat

Attach `lao-typography-knowledge.md`, `lao_check.py` and the Noto Sans Lao font, then start with:

> Follow the rules in lao-typography-knowledge.md for all Lao text. Use Noto Sans Lao from the attached font file, run lao_check.py on any file you make, and tell me what you could not verify.

## Codex and other coding agents

Use [`../lao_typography_design/AGENTS.md`](../lao_typography_design/AGENTS.md): copy it to your repository root (or append it to the `AGENTS.md` you already have) and keep the `references/`, `scripts/` and `assets/` folders beside it. The repository also contains a Codex plugin manifest (`lao-typography-plugin/.codex-plugin/`).

## What to expect

- The Code Interpreter sandbox varies. The GPT is told to check which tools exist and to say so when it cannot render a preview. Word, PowerPoint, Excel and HTML files can be built with Python libraries; PDF conversion and page previews need LibreOffice or WeasyPrint, which may not be installed there.
- The GPT still cannot judge Lao spelling or meaning reliably. Have a native reader confirm anything official, legal, financial or published.
