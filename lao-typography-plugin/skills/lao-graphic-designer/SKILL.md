# Lao graphic design

> **Default font:** unless the user names a font, use **Noto Sans Lao** for all Lao text, designs and fonts, automatically and without asking. Use another font (for example Phetsarath OT or Noto Serif Lao) only when the user, an official template or a brand guide asks for it.

Build around the supplied copy, dimensions, audience, and output format. Preserve approved wording and brand requirements.

## Text and artwork

Create backgrounds and illustrations without writing, then compose Lao text using real font-set text in the layout tool. Inspect generated artwork for accidental writing. Do not rely on image generation or inpainting to spell or repair Lao words.

Keep text editable in the working file. For a flattened source, reconstruct text in a separate layer when authorized; retain a comparison with the original. Outline a final wordmark only when required by the delivery workflow, keeping an editable master.

## Typography and layout

- Use a Lao-capable font and shaping engine; inspect the exact font's terms before embedding, redistribution, or upload.
- Allow room above and below the baseline for vowel and tone marks. Start with generous leading, zero tracking, and real font weights. Avoid artificial italic, stretching, or effects that hide marks.
- Keep syllables and base/mark clusters intact. Do not insert word spaces just to fit a headline.
- Distinguish Lao and Thai text blocks, preserve supplied names and numbers, and balance Lao and Latin by apparent size.
- Check hierarchy and readability at the final physical size or screen scale. Apply requested print dimensions, bleed, and color requirements to the actual export.

Inspect the exported file, not only the editor canvas. Check spelling against approved copy and examine marks at close zoom and normal viewing size. Deliver requested exports plus editable source when the workflow supports it, identifying font dependencies and unverified language or rendering details.
